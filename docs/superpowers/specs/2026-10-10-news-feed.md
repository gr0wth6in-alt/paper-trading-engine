# Approved crypto news feed specification

Project: `C:\Users\Sulihin\Videos\New folder\paper-trading-engine`.

1. Aggregate public RSS/Atom feeds only. No API keys, no HTML scraping. Built-in sources:
   CoinDesk, Cointelegraph, Decrypt, The Block, Bitcoin Magazine, CryptoPotato, Bitcoinist.
   `PAPER_NEWS_FEEDS` (JSON list of `{name, url}`, https only, 1-20) replaces the defaults;
   `PAPER_NEWS_ENABLED` turns the feature off.
2. A lifespan background poller fetches every `PAPER_NEWS_POLL_SECONDS` (default 300,
   range 60-3600). Storage is in memory only, newest 500 items. No SQLite writes or schema
   changes. Each source has its own exponential backoff; one failing source never blocks
   the others.
3. Never block the event loop: async HTTP with timeouts, a 2 MiB body cap, conditional
   requests (ETag/Last-Modified), and feed parsing in a single spawned worker process
   (a thread was measured stalling the loop up to 338 ms because feedparser holds the GIL).
4. All feed HTML is stripped to plain text on the backend. Only http/https article links
   are kept. The frontend renders text only and never uses `dangerouslySetInnerHTML`.
5. Items are tagged with base tickers from the active symbol list (ticker whole-word match,
   case-sensitive, `$BTC` allowed) plus a basic name alias map (Bitcoin, Ethereum, ...).
6. UI: a dedicated News view (source filter, search, related-to-current-market filter,
   relative time, external links) and a three-item strip under the Terminal chart.

## Dependency decision (supersedes "no new external dependencies" for this feature)

- `feedparser==6.0.14` (+ its `feedparser-sgmllib`) is added for robust RSS/Atom parsing.
  It does not resolve external XML entities.
- `httpx2==2.13.1` moves from dev to runtime and is pinned exactly. It was briefly suspected
  of being a typosquat; it is the maintained httpx fork published by the original httpx
  author (github.com/pydantic/httpx2), and Starlette 1.7's TestClient imports it first and
  deprecates plain `httpx`. Legacy `httpx`/`httpcore` were removed from the environment.
